# FIM 590 - Data Analytics with SQL (Fall 2026)

NC State University - Master of Financial Mathematics - 1 credit - Mondays 6:00 PM
Instructor: Robert Graham Carroll Jr (rgcarrol@ncsu.edu)

Learn to answer financial questions with SQL, using real-world-style market data.
Everything you need is on GitHub and in VS Code.

Each assignment folder inside it has a README with the instructions.

## How grading works (short version)

- You push your `.sql` answer files to GitHub.
- A practice checker runs automatically and shows a score and hints. Fix and push again as often as you like.
- Your instructor records the official grade from the last version you pushed before the deadline.
  Only your `.sql` answer files count.

Grading breakdown (syllabus): class assignments 70% (all assignments are mandatory) and a final in-class assignment 30%.
